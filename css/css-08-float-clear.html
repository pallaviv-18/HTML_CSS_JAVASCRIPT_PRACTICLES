Using Float

FLOAT

The CSS float property is used to position an element to the left or right of its container.

Other content can flow around a floated element. In this example, the blue box is floated to the left and the text flows around it.

Float was traditionally used for creating layouts and positioning images alongside text.

Using Clear

The clear property prevents an element from appearing beside floated elements.

Here, clear: both; is used so this section starts below the floated box.
