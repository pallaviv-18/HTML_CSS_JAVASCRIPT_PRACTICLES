CSS Experiment 36 - Z-Index

Demonstration of the CSS z-index property for controlling the stacking order of positioned elements.

Box 1
z-index: 1
Box 2
z-index: 3
Box 3
z-index: 2

About z-index

The z-index property controls the stacking order of positioned elements.

An element with a higher z-index appears in front of an element with a lower z-index.

In this example, Box 2 has the highest z-index value (3), so it appears above Box 1 and Box 3.
