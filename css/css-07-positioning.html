CSS Positioning

The CSS position property controls how an element is placed on a webpage. This experiment demonstrates static, relative, absolute, fixed and sticky positioning.

1. Static Position

position: static

Static is the default position of an HTML element. The element follows the normal document flow.

2. Relative Position

position: relative

A relative element remains in the normal document flow, but can be moved using top, bottom, left or right.

3. Absolute Position

position: absolute

An absolutely positioned element is positioned relative to its nearest positioned ancestor.

4. Fixed Position

Scroll the page and notice the fixed message at the bottom-right corner.

A fixed element stays in the same position relative to the browser window even when the page is scrolled.

5. Sticky Position

Sticky Heading

Scroll inside this box to see the sticky heading remain at the top.

Sticky positioning behaves like relative positioning until a specified scrolling position is reached.

After reaching the top position, the element remains visible while its container is scrolling.

This technique is commonly used for navigation headers and section headings.

Continue scrolling to observe the sticky effect.

Position Property Comparison

Position Description
Static Default position and follows normal flow.
Relative Moves relative to its normal position.
Absolute Positioned relative to a positioned ancestor.
Fixed Remains fixed relative to the browser window.
Sticky Sticks to a specified position during scrolling.
