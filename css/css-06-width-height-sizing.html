Width, Height & Sizing

CSS width and height properties control the size of HTML elements. Different units and sizing properties can be used to create flexible and responsive layouts.

1. Fixed Width

Width: 300px

The element has a fixed width of 300 pixels.

2. Percentage Width

Width: 80%

Percentage width changes according to the size of its parent element.

3. Full Width

Width: 100%

This element occupies the complete available width.

4. Fixed Height

Height: 150px

The element has a fixed height of 150 pixels.

5. Min & Max Width

Minimum width: 200px
Maximum width: 400px

min-width and max-width restrict how small or large an element can become.

6. Min & Max Height

This box has a minimum height of 100px and a maximum height of 180px. If the content becomes larger, scrolling is enabled using overflow.

7. Viewport Sizing

Width: 70vw
Minimum Height: 20vh

vw represents viewport width and vh represents viewport height.

Sizing Properties Used

  • width - sets the width of an element.
  • height - sets the height of an element.
  • min-width - sets the minimum width.
  • max-width - sets the maximum width.
  • min-height - sets the minimum height.
  • max-height - sets the maximum height.
  • vw - viewport width unit.
  • vh - viewport height unit.
