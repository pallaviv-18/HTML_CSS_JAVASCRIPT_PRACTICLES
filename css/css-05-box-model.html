CSS Box Model

Understanding the CSS Box Model

Every HTML element can be considered as a box. The CSS box model consists of four main parts: content, padding, border and margin.

Content

This is the content area of the element.

The space around the content is padding, followed by the border and margin.

1. Content

Content Area

Content is the actual text, image or other information inside an element.

2. Padding

Padding creates space inside the border.

The padding property controls the space between the content and border.

3. Border

This element has a thick border.

The border surrounds the content and padding.

4. Margin

Margin creates space outside the border.

Margin controls the space between an element and surrounding elements.

5. Complete Box Model

Content
Padding → Border → Margin

This example combines content, padding, border and margin to demonstrate the complete CSS box model.
