Experiment 1 - Inline, Internal and External CSS

Three Ways to Apply CSS

1. Inline CSS

This paragraph is styled using Inline CSS.

Inline CSS is written directly inside the style attribute of an HTML element.

2. Internal CSS

This section is styled using Internal CSS.

Internal CSS is written inside the <style> tag in the HTML document.

3. External CSS

This section is styled using External CSS.

External CSS is written in a separate .css file and connected using the <link> element.

Comparison

CSS Type Where It Is Written
Inline CSS Inside the HTML element
Internal CSS Inside the <style> tag
External CSS Inside a separate CSS file
